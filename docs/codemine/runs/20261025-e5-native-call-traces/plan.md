# E5 native call traces and internal calls

Base main `439621e` (#222). Preserve the accepted E1/E2/E3/E4 designs and two executions. Observe the existing recording replay; never run a third EVM, patch upstream or replace Arc's official execution factory with generic Ethereum execution.

## Contract and decisions

Attach bounded observers to the pinned official Arc inspector and StableNet VM logger. Record transaction roots and every observed CALL/CALLCODE/DELEGATECALL/STATICCALL/CREATE/CREATE2/SELFDESTRUCT in preorder with exact transaction identity, parent ordinal, caller/target, optional value/target, gas, input/output and local error. Preserve attempted calls; derive ancestor-reverted status from the whole tree. A non-root frame is an internal call, not necessarily a successful value transfer. Native USDC/system accounting continues to use the verified journal. Pre-block/finalization transitions remain separate and are not invented user transactions. Explicitly document native precompile/authorization and hook coverage limits; the call list has no independent commitment in state/receipt roots.

Extend EXR1 metadata with an optional, explicitly versioned CallTraces set. Missing means legacy/not collected, including an empty block; a present empty set proves only a successfully observed transaction-empty replay. Existing frame protocol, old payload readability and seven queues stay intact. Old strict readers must reject the new metadata; upgrade reader and producer together. Bound total frames, depth, individual/aggregate bytes and errors before retaining data; overflow fails the whole replay, never truncates it as complete. Normalize transaction-root gas fields against the verified transaction/receipt. Go rechecks graph structure and root transaction/receipt consistency, profile and result identity before a writer sees data. The producer's replay provenance is distinct from cryptographic proof of every child.

Persist trace metadata/frames in the existing transactions part transaction, with a parameter-bound, immutable exact-input contract. No eighth writer/pool/connection. Public reads use the existing reserved snapshot, visible-height and rewind gates. Provide bounded fork-pinned block and transaction pages, including explicit internal-call classification; missing collection differs from a collected empty result. Preserve richer data separately from the legacy InternalTransaction model/API, whose missing target/value/path/provenance cannot represent it faithfully. Rewind deletes abandoned trace records including unpublished work; current-prefix generation rebinding must not relabel an old payload. Trace records are permanent indexed data, independent of raw/native GC, ACK remains gated by all seven parts and final publication.
