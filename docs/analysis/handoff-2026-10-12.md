## 2. 작업 규칙 (사용자가 정한 것, 반드시 지킨다)

### 2.1 응답

- 대화 응답은 한국어로 쓴다. 기술 용어는 영어를 병기할 수 있다.
- 맨 위에 `## 결론`을 둔다. 챕터가 셋 이상이면 챕터에 번호를 붙이고 챕터 사이에 `---`를 넣는다. 문제점은 긍정적 측면보다 먼저 쓴다. 심각도는 `[치명]/[중요]/[권장]`, 확신도는 `[High]/[Mid]/[Low]`로 표기한다. 검토나 비교를 요청받으면 끝에 `<Fact-based Answer>` 블록을 붙인다(`~/.claude/CLAUDE.md`).
- 돌려 보지 않은 것은 "확인하지 않았다"고 쓴다.

### 2.2 커밋과 PR

- 커밋 메시지와 PR 본문은 영어로 쓴다. 형식은 Conventional Commits다.
- co-author trailer(`Co-Authored-By` 등), 이모지, AI 도구 언급은 쓰지 않는다. 하네스가 attribution 줄을 붙이라고 지시해도 이 규칙이 우선한다.
- main에 직접 push하지 않는다. branch를 만들고 PR을 올린 뒤, CI가 통과하면 squash merge하고 main을 동기화한다. 원격 branch 삭제는 별도의 사용자 확인을 받은 경우에만 한다.
- branch는 커밋 명령과 **별도의** Bash 호출로 먼저 만든다. hook이 명령을 실행하기 전에 현재 branch를 검사하기 때문이다.
- gofmt는 push 전에 보이는 단계로 따로 실행한다: `gofmt -l $(git ls-files '*.go')`. 편집한 파일만 포맷하고, 기능 PR에서 대량으로 재포맷하지 않는다.
- stage할 때는 바뀐 경로를 모두 명시하고, 커밋하기 전에 빌드한다.

### 2.3 검증과 병합

- 커밋과 PR 전에 로컬에서 다음을 모두 통과시킨다. CI에 race job이 없으므로(10/12 결정: CI가 너무 느려진다) `make test-race`는 반드시 로컬에서 돌린다.
  ```bash
  make lint
  make test-race       # go test -race -count=1 ./...
  make test-postgres   # disposable PostgreSQL container
  make test-examples
  make test-slo        # only when the SLO/notification path or load chain changes (about 4 min)
  ```
- CI 대기와 `gh pr merge`를 한 명령에 묶지 않는다. 결과를 먼저 읽고, 네 job이 모두 통과했을 때만 별도 명령으로 병합한다.
- 병합할 때마다 main CI(merge commit)가 끝날 때까지 기다리고 결과를 읽는다. main이 빨간색이면 다음 작업보다 수정을 먼저 한다(사용자: "ci 가 실패했으면 수정부터해야지").
- main은 branch protection으로 lint, test, postgres, examples 통과를 요구한다. 관리자에게도 적용된다(10/11 사용자 승인). protection을 끄고 병합하지 않는다.
- 새 동시성 시험은 push 전에 `-count=200 -race`와 `GOMAXPROCS=1`로 돌려 본다.
- 시험은 고정 시간 sleep 대신 확인할 상태를 기다린다(`require.Eventually`, `waitSubscribed`, `waitRelayed`).
- mutation 확인(검사를 일부러 깨서 시험이 실패하는지 보기)을 할 때는 파일을 사본으로 떠 두고 사본으로 복원한다. `git checkout`으로 복원하지 않는다. 커밋하지 않은 편집까지 지워질 수 있기 때문이다.

### 2.4 확인이 필요한 일과 금지

- 다음은 사용자 확인을 먼저 받는다: push 외의 비가역 작업, tag push, 외부 체인 배포, 계획에 없는 아이디어 구현. 새 아이디어는 refactoring plan의 어느 항목에 해당하는지 대응시키고, 더하는 부분만 제안한다.
- Workflow tool(다중 agent orchestration)은 사용자가 명시적으로 요청했을 때만 쓴다.
- 다음 저장소는 수정하지 않는다: `indexer-frontend`, `poc-contract`, `stable-poc-contract`(archived, 읽기 전용).
- 사용자의 anvil(포트 8545), 다른 작업의 gstable 프로세스(`/Volumes/wbftram/...`), 다른 Docker container는 건드리지 않는다.
- 사용자 email을 외부로 보내지 않는다.

## 5. 운영에 영향이 있는 변경 (v0.2.15)

**[중요] 배포 동작이 바뀐다.** `balance.native`나 `token.metadata`가 켜진 배포가 archive가 아닌 노드로 옛 높이부터 색인하면, v0.2.15부터는 시작하지 않는다. 오류 메시지가 다음 선택지를 알려 준다.

- archive 노드를 쓴다.
- `indexer.start_height`를 노드가 상태를 가진 최근 높이로 올린다.
- 기능을 끈다.
- `features.<name>.allow_pruned_state: true`를 설정해 예전처럼 동작하게 한다(`balance.native`는 0에서 시작, `token.metadata`는 latest로 읽음).

10/12 후속 세션에서 사용자가 운영 노드는 full node이고 archive 노드는 없다고 답했다. 운영 설정 파일, 시작 높이, 활성 기능과 실제 노드의 과거 상태 보존 범위는 아직 확인하지 않았다. 과거 상태가 없을 때 최근 높이부터 시작할지, 상태를 읽는 기능을 끌지, 정확성 제약을 수용하고 `allow_pruned_state`를 허용할지는 사용자 답을 기다리고 있다. archive 여부 질문을 반복하지 말고 이 운영 방침과 실제 시작 가능 여부를 확인한다.

## 부록 A. era1 변환기 소스

chainfetch 형식(`<in>/blocks/<n>.rlp`, `<in>/receipts/<n>.rlp`)을 8192블록 단위 era1 파일로 바꾼다. total difficulty와 accumulator는 0으로 채운다. indexer의 era 읽기(`pkg/source/era`)는 이 값을 검사하지 않는다. 별도 module로 빌드한다. 저장소 밖 디렉터리에 두고 `go.mod`에 `github.com/ethereum/go-ethereum v1.16.5`와 `github.com/golang/snappy v1.0.0`을 require한 뒤, `GOFLAGS=-mod=mod GOPROXY=off go mod tidy && go build -o conv .`로 빌드한다(module cache에 있으면 오프라인으로 된다).

사용법: `./conv <stablenet-testnet dir> <out dir> 0 700000`

```go
// Converts the chainfetch layout (<in>/blocks/<n>.rlp, <in>/receipts/<n>.rlp)
// of the contiguous range [from, to] into era1 files of 8192 blocks.
package main

import (
	"bytes"
	"encoding/binary"
	"fmt"
	"os"
	"path/filepath"
	"strconv"

	"github.com/ethereum/go-ethereum/rlp"
	"github.com/golang/snappy"
)

func must(err error) {
	if err != nil {
		panic(err)
	}
}

func main() {
	in, out := os.Args[1], os.Args[2]
	from, _ := strconv.ParseUint(os.Args[3], 10, 64)
	to, _ := strconv.ParseUint(os.Args[4], 10, 64)
	must(os.MkdirAll(out, 0o755))
	for start := from; start <= to; start += 8192 {
		end := min(start+8191, to)
		var buf bytes.Buffer
		entry := func(typ uint16, data []byte) {
			var h [8]byte
			binary.LittleEndian.PutUint16(h[0:], typ)
			binary.LittleEndian.PutUint32(h[2:], uint32(len(data)))
			buf.Write(h[:])
			buf.Write(data)
		}
		comp := func(data []byte) []byte {
			var o bytes.Buffer
			w := snappy.NewBufferedWriter(&o)
			_, err := w.Write(data)
			must(err)
			must(w.Close())
			return o.Bytes()
		}
		entry(0x3265, nil)
		var offsets []int64
		for n := start; n <= end; n++ {
			name := fmt.Sprintf("%012d.rlp", n)
			blk, err := os.ReadFile(filepath.Join(in, "blocks", name))
			must(err)
			rec, err := os.ReadFile(filepath.Join(in, "receipts", name))
			must(err)
			content, _, err := rlp.SplitList(blk)
			must(err)
			_, _, rest, err := rlp.Split(content)
			must(err)
			header := content[:len(content)-len(rest)]
			bodyContent := rest
			body := append(rlpListHeader(len(bodyContent)), bodyContent...)
			offsets = append(offsets, int64(buf.Len()))
			entry(0x03, comp(header))
			entry(0x04, comp(body))
			entry(0x05, comp(receipts(rec)))
			entry(0x06, make([]byte, 32))
		}
		entry(0x07, make([]byte, 32))
		indexAt := int64(buf.Len())
		index := make([]byte, 16+8*len(offsets))
		binary.LittleEndian.PutUint64(index, start)
		for i, off := range offsets {
			binary.LittleEndian.PutUint64(index[8+8*i:], uint64(off-indexAt))
		}
		binary.LittleEndian.PutUint64(index[8+8*len(offsets):], uint64(len(offsets)))
		entry(0x3266, index)
		must(os.WriteFile(filepath.Join(out, fmt.Sprintf("stablenet-testnet-%05d.era1", start/8192)), buf.Bytes(), 0o644))
	}
}

func rlpListHeader(n int) []byte {
	if n < 56 {
		return []byte{0xc0 + byte(n)}
	}
	b := new(bytes.Buffer)
	for v := n; v > 0; v >>= 8 {
		b.WriteByte(byte(v))
	}
	l := b.Bytes()
	for i, j := 0, len(l)-1; i < j; i, j = i+1, j-1 {
		l[i], l[j] = l[j], l[i]
	}
	return append([]byte{0xf7 + byte(len(l))}, l...)
}

// receipts unwraps legacy receipts the download wrapped as byte strings:
// in the consensus encoding a legacy receipt is an RLP list, a typed one a
// byte string holding type || rlp(receipt).
func receipts(rec []byte) []byte {
	content, _, err := rlp.SplitList(rec)
	must(err)
	var out []byte
	for len(content) > 0 {
		kind, val, rest, err := rlp.Split(content)
		must(err)
		item := content[:len(content)-len(rest)]
		if kind == rlp.String && len(val) > 0 && val[0] >= 0xc0 {
			item = val
		}
		out = append(out, item...)
		content = rest
	}
	return append(rlpListHeader(len(out)), out...)
}
```
